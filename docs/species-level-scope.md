# 物种级范围

确认日期：2026-09-24。

- 植物目录、识别结果和训练类别只到**物种级**，以现有稳定物种 ID 关联。
- 不建立品种表、品种业务字段、品种筛选或品种识别类别。
- 四季桂、金桂等来源名称统一关联木犀的物种记录；不要求区分其具体品种。
- 来源中的原始名称和原始学名仅作为资料溯源保留，不作为产品需要管理的品种实体。
- 新增目录名称不等于模型新增支持；训练支持清单仍只登记实际训练完成的物种。
- 物种级简化不意味着可以合并不同物种；混合类群、杂交植物和跨物种同名，不能任意归到一个亲本或同属物种。

名单中的 `catalogMapping.speciesId` 是物种级关联；
`catalogMapping.level` 仅说明关联依据，不是新的产品分类层级。
映射资料在 `docs/research/landscape-plants-db-mapping-20260924.json`；
本次文件映射不会自动写入数据库、修改训练标签或切换线上模型。
