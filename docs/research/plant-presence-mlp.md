# 植物存在二分类：32 单元 MLP 离线对照

2026-09-23。本次实验不切换线上模型，也不改变正在运行的物种回放实验所用门控。

## 实际实现与数据

在已有 ImageNet ResNet50 的冻结、L2 归一化 2048 维特征上，增加
`Linear(2048,32) → ReLU → Linear(32,2)` 实验头。原线性头默认路径保留。
训练入口增加 `plant_presence train --head-type mlp32 --backbone imagenet`；
新头使用独立的 format=2 文件，严格验证结构、形状、有限值和编码器身份。
旧 format=1 文件不重写。元数据声明二分类的物种集合不适用，不声称识别所有物种。

复用已有 Open Images V7 明确人工 Plant=1/0 标签的公开授权数据：
训练 3,992 张、验证 999 张、开发测试 999 张。没有使用私人照片。
训练前保存计划，最多 100 epoch，随机种子 20260922；
仅按验证集交叉熵选择权重，并在验证集选择植物召回率至少 95% 的阈值。
实际选择第 2 epoch，17 epoch 后停止。没有按测试结果调权重或阈值。

## 结果：不采用此版本

两头使用同一组测试照片；阈值分别在各自验证分数上按同一召回目标确定。

| 指标 | 原线性头 | MLP32 |
| --- | ---: | ---: |
| 验证植物召回率 | 95.00% | 95.00% |
| 验证非植物误放行率 | 18.84% | 22.24% |
| 测试植物召回率 | 463/499，92.79% | 468/499，93.79% |
| 测试非植物误放行率 | 109/500，21.80% | 117/500，23.40% |

MLP 在验证集上已无优势；开发测试表现为少拒绝 5 张植物、多误放行 8 张非植物。
不足以支持替换，且不能把“新增隐藏层”当作必然的准确率提升。
此表比较的是验证召回目标 95% 的独立二分类头，不是线上使用更保守阈值时的指标。
该测试集之前已用于实验，不是全新独立最终验收集。
