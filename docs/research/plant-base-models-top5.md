## 一、任务边界

以“一株待识别植物”的拍摄场景为主任务，不扩展成街景多目标检测/分割项目。
正常输入有植物不代表任意坏输入都应强制给出物种；非植物、库外植物和细节不足照片
仍需独立评估拒识。低物种分数不能直接解释为“不是植物”。

正常输出是至多五个不同物种候选，经稳定 Species ID 和已核实名称关系连接到中文展示。
不靠多个中文别名/异名占满五个位置，也不为凑足五项编造候选。

## 二、Pl@ntNet 的三个对象必须区分

### A. Pl@ntNet 在线识别 API（已排除，仅保留历史调研）

不是一份可直接微调的权重；用户已明确不采用，不作为评测或产品接入建议。
官方提供 `all` 项目、`organs=auto`、`nb-results` 和 `no-reject` 等参数；
初始比较使用单张照片、`nb-results=5`，不关闭默认的非植物拒识。
项目/地域筛选要用官方已存在的项目，不能自行发明“中国 flora ID”。[S1]

截至本轮查看，免费方案为每天 500 次识别；另有付费及特定非营利方案。
免费小程序不自动符合额外非营利资格，使用限制和署名需按官方条款确认。[S2]
照片需要传至第三方；服务条款区分图像处理与查询日志，不能笼统承诺“什么都不留存”。[S3]
本轮没开账号、没索要/读取密钥、没提交照片或付费。

没有找到并核实与当前线上 API 同版本的全球分类器公开权重。
这是本轮核实范围，不是宣称 Pl@ntNet 从未发布任何模型。

### B. Pl@ntNet-300K 数据集、代码与旧基准模型

官方 GitHub 仓库包含训练代码及公开预训练模型入口，示例使用 ResNet18 的
1,081 类分类头，并明确说明迁移到另一数据集时需要换最后一层。[S4]
训练 CLI 支持多种网络，不等于这些网络的每个预训练 checkpoint 都已核实可下载。
实际共享页返回 HTTP 200 的动态页面壳，本轮未取得文件级目录或验证独立权重许可。

**版本不能混用**：

- 仓库 README 仍介绍 306,146 张 / 1,081 类的旧数据及 0–1080 类别索引。
- Zenodo V2 页面为 306,087 张 / 1,000 类；本轮实际下载其小型物种 CSV，确认 1,000 行。[S5]
- 不能把新 V2 的类别表直接套在旧 1,081 维权重上；更不能把这 1,000 类当成中国常见千种。

代码采用 BSD-2-Clause；照片有逐图许可，含限制用途的许可。
不能将代码许可推定为外部权重或所有照片的许可。本轮未下载照片、数据大包或 checkpoint。
当前路线是 **官方预训练权重优先的本地评估**，不是先自行训练。
先核对实际共享 checkpoint 的架构和标签版本，再决定是否需要换头或微调。
README 的 1,081 类代码只是已核实的示例，不能据此推断完整共享目录没有 V2 权重。
权重、类别输出顺序、数据版本及评估结果必须一起保存。
如果之后再适配中国目标类别，需要另存新分类头和版本，不能继续声称是未改动的 V2 原始分类器。

### C. PlantCLEF / Pl@ntNet 的植物专用 DINOv2

官方公开模型使用 DINOv2 ViT-B/14，原分类任务为欧洲西南部 7,806 类；
发布记录标明 CC BY 4.0，并提供类别表。[S6]
此前项目已做过类别覆盖检查，详见 `plantclef-dinov2-coverage.md`，本轮不重复算名单。

**必须修正原先过于依赖“旧分类头覆盖”的判断：**

- 直接保留欧洲分类头上线：覆盖中国目标植物有明显限制。
- 去掉旧头，用其视觉骨干训练中国植物分类头：是合理的迁移学习候选；
  旧输出列表没有某种植物，不意味着骨干无法学习它。
- 应评估 `onlyclassifier_then_all` 版本的视觉骨干；`onlyclassifier` 版本只训练了头，
  不能把其冻结骨干也说成经过植物专用全模型微调。

本项目已有该发布包的安全转换/加载扩展点，但文件仍未完整准备。
本轮没有解决原大文件下载阻塞，也没有成功运行这个模型。

## 三、候选模型的取舍

| 候选 | 在一株中的角色 | 本轮判断 |
| --- | --- | --- |
| 现有 BioCLIP v1 召回 + v2 重排 | 保留线上对照 | 衡量改进不能只与随机分类器比 |
| BioCLIP 2 + 新分类头 | 本地训练候选 A | 已有权重/代码可复用，减少工程变量；尚无中国目标集可靠成绩 |
| PlantCLEF-DINOv2 `onlyclassifier_then_all` + 新头 | 本地训练候选 B | 植物域初始化值得比较；旧头换掉，不能直接部署欧洲标签 |
| Pl@ntNet-300K 官方预训练模型 | 用户选定的本地对照方案 | 先核对实际 checkpoint/类别表是否对应 V2，再做本地 Top-5，不预设需要先训练 |
| Pl@ntNet API | 已排除 | 不用于推理、评测或生成训练标签 |
| BioCLIP 2.5 ViT-H/14 | 后续高资源候选 | 官方已发布且为 MIT；比当前 ViT-L 系列规模更大，不能假定适合本机。[S7] |
| DINOv3 小/中型骨干 | 可选通用视觉对照 | 官方有线性评估/微调路线；下载许可为定制 DINOv3 License，需单独确认。[S8] |

当前本地对照集合是 **现有方案、BioCLIP 2 新头、PlantCLEF-DINOv2 新头、
Pl@ntNet-300K 官方预训练模型**。不接入外部识别 API，也不需要 Pl@ntNet API key。
不同时启动所有模型，不因名称更新就替换现有系统。

“B 模型参数更少”不等于其 CPU 推理更快：
PlantCLEF 原配置为 518×518，而本项目 BioCLIP 使用另一套固定预处理。
必须以实际输入分辨率测试延迟和峰值内存；不能只比参数量。
既有三类训练实验只能证明链路可运行，不是可靠的 Top-5 识别实验。

## 四、统一 Top-5 评估规则

可执行约定另存于 `plant-top5-evaluation-plan.json`。

### 主指标

对固定的中国目标植物测试集：

```text
Top-5 = 真实物种 ID 出现在前 5 个不同物种候选中的照片数 / 测试照片总数
```

- 所有模型使用同一张照片、同一份参考答案和同一份预先冻结的名称映射。
- 返回的学名要核对异名后对应 Species ID；不能单凭中文显示字符串判断。
- 目标物种不在某模型的输出范围内，端到端评估记未命中，不偷偷删除这些样本。
- 返回错误、超时或未给出候选，也不从主指标分母剔除；另报技术成功率/覆盖率。
- 分别报告整体验证集 Top-1/Top-5 和逐物种宏平均 Top-5，防止常见大类掩盖小类失败。
- 需要多于 5 个物种才能有意义地评价 Top-5。三类冒烟中的 Top-3 满分不能替代此指标。

### 必要的诊断项

1. 当前两级方案记录 **Recall@50**：正确物种没被 v1 召回，v2 重排无法挽回。
2. 记录类别覆盖和名称映射覆盖，区分“不支持该种”与“支持但识别错误”。
3. 独立测非植物误接受率，以及库外植物被强行判为已知种的比例。
4. 记录单图延迟中位数/P95、冷启动、进程峰值内存和本地资源占用。
5. 无校准证据时，softmax、相似度或供应商 score 不包装成真实正确概率。

测试集不能参与训练、调参或阈值选择；同观察、近重复、同拍摄者组保持隔离。
还要标记基础模型预训练重叠尚未排除的风险，不能将这种数据宣称为完全独立 benchmark。
只用已授权照片；用户使用识别功能不等于授权训练、外传给另一服务或建立测试图库。

## 五、实际训练路线（尚未执行）

1. 冻结一批有可靠标签、包括中国日常盆栽/绿化/郊野/作物场景的训练与测试数据。
   不再把“先整理完全国千种名录”当作训练前置大工程。
2. 对 A/B 两个骨干分别提取特征，用**相同类别与样本**训练各自的新分类头。
3. 用验证集选择超参/拒识阈值，再在固定测试集比较 Top-1/Top-5。
4. 只有冻结特征基线确有改善空间，再评估末端层/适配器微调及额外算力；
   收费 GPU 必须另行批准。
5. Pl@ntNet 分支先使用官方预训练 checkpoint 和其原配类别索引，
   在同一套中国测试照片上比较 Top-1/Top-5；版本和覆盖范围如实记录。
   若没有核实对应 V2 的权重，不将其他版本改名为 V2。
   未覆盖物种计未命中，不缩小分母。之后才根据结果决定是否微调；
   不以在线识别 API 代替本地分支。
