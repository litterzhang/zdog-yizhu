## 来源和边界

- 逐页读取了百度百科的植物词条，保存实际页面地址、学名字段、获取时间和快照 SHA。多义词先选择植物义项；错误跳转不当作植物证据。
- 使用 GBIF 官方分类响应复核鹅掌柴、孔雀竹芋、珍珠吊兰、蛇莓的新旧名称，以及草莓杂交符号重复记录。未把 API 名称匹配 confidence 当作照片识别置信度。
- 珍珠吊兰通过接受种的异名列表核对作者，未采用仅同拼写、作者不同的匹配。
- 按用户要求只到种级，种下品种/亚种回归所属种；杂交分类实体不被任意替换为亲本。
- 百合、康乃馨、羽扇豆、鼠尾草等名称在园艺市场可能用于多个种；本计划限定为表中具体物种。图片仍需按来源学名与分类证据采集，不按商品名自动标注。
- 既有 7 条早期规划关联保留其原核验限制；本次没有把之前植物智返回 403 的页面标成已访问。另一次维基接口查询连接超时，未采用其结果。
- 原文的药用、食用、毒性及养护描述均未写入知识库。
