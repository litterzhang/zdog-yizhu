## 接口与安全

`recognition_plantnet.py` 将两级输出适配为既有 `recognize(image, top_k=5)` 契约：

- 二分类拒绝时返回 `uncertain`、空候选和 `nonplant_gate`，不编造物种。
- 通过时最多返回五个稳定物种 ID，`confidence=null`；分数不当作正确概率。
- 隐藏的首选候选不能被悄悄替换为另一个“成功”物种。
- 原始两级信息与来源版本保存在原识别结果中，不覆盖用户确认/纠正。
- 运行时核对注册的模型哈希、两级权重、预处理及保留的 A 参数。
  缺失/不匹配明确失败，不静默退回 BioCLIP。
- 只加载所选方案，不同时初始化 BioCLIP 大模型。没有外发用户图片给识别服务。
- 客户端不能在请求体中指定算法；方案仍由服务端选择。

`/api/health` 的 `recognition_solution` 包含模型版本、当前 592 类范围、
420/172 类组成和 `plantPresenceGate=true`。
元数据 ID 为 `plantnet-china`；原始预训练权重自己的合同
`plantnet-300k-resnet50` 仍保留其 A=420 范围，不伪造原权重能输出新类别。
