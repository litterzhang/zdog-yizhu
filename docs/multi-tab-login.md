# 四 Tab 与登录界面

已按最新要求直接用 Taro 实现，不再生成 UI 图片。

| Tab | 内容 |
| --- | --- |
| 发现 | 拍照/相册选择、照片预览、开始识别；不包含历史、最近观察或历史入口 |
| 足迹 | 「发现」产生的全部识别记录，按日期倒序分组，显示状态并可重新打开结果 |
| 株记 | 用户「记住这一株」的个体档案；按昵称/物种搜索，进入档案继续观察 |
| 我的 | 游客/已验证账号状态、登录入口、数据与隐私、来源、产品说明与清空操作 |

四个主页面使用 Taro 标准 tabBar；识别结果、植物详情、登录为独立次级页面。
发现页移除顶部品牌栏目标签、观察徽标、大标题及副文案；保留插画、简短图注和拍照/相册入口，收紧顶部留白。
选图后在按钮附近展示上传用途；已登录用户点击“上传并识别”直接启动，不再二次弹窗确认。选图本身不上传，未登录仍先引导登录，保留上传状态、防重复提交和失败反馈。
我的、足迹、株记页不再重复显示页内栏目标签、大标题及说明文案；保留原生导航标题和底部 Tab。
我的直接展示账号卡片，足迹/株记已登录时直接展示记录操作，游客仅显示登录提示。
保留系统导航栏自带的返回箭头，不再在内容区重复提供“返回”按钮。
结果、植物详情、登录及名录页不再提供页内首页图标，包括记录不可用状态。
通过平台原生返回导航或主页面底部 Tab 切换；“重新选择照片”等业务操作保持原有行为。

## 植物名录

发现页提供“浏览植物名录”入口，不新增第五个 Tab，也不把名录混入私人足迹。
无需登录即可按目 → 科 → 属 → 种浏览、分页搜索中文名/学名，并查看来源。
名录默认“有中文名”，可切换“全部参考”；分类节点中文优先、学名次要展示。
支持简体与繁体原文/别名搜索，未收录中文名的条目明确提示，不编造名称。
草本/灌木/乔木/藤本为独立筛选；仅 5 个条目有核实的形态数据，其余未知。
结果页可从完整名录更正物种；档案编辑使用分页搜索，不把十万级数据塞入 Picker。
物种深链兼容 Taro H5 保留编码的查询参数与小程序已解码参数。

## 游客与登录态展示

- 发现不展示整块登录卡；游客仍可选图和预览，到主动启动识别时才引导登录。
- 我的只保留“你好，草木观察者”账号卡作为登录入口，不再额外叠加手账登录卡；私人统计在登录后展示。
- 足迹、株记未登录时内容区只显示一个登录提示，不渲染重复标题、搜索、筛选、数量、列表或业务空状态。
- 校验登录期间显示校验状态；只有 `authenticated` 且存在已验证用户时才显示私有内容。
- 登录后正常区分空数据与已有记录；退出后立即恢复游客布局，不删除服务器记录。

## 确认识别结果

结果页直接提供“确认是「首选物种」”“选择其他候选”“暂不确认物种”。
照片和候选名称优先展示，不再堆叠栏目标题、名录数量、原始结果说明和建档引导。
确认成功通过状态标签及短提示反馈，不额外重复一整块确认卡片。
只保留页尾一处安全说明；物种简介有资料时按需展开，保留 AI/复核标记与出处，无资料时不显示占位说明。
服务来源、版本及候选排序说明收进“识别信息”，分类与来源仍可跳转查看。
确认的是当前足迹中的用户判断，原始算法返回不会改变。
如果足迹已经关联株记，确认、更改或清空物种也会同步株记，以最近一次手动修改为准；
不会覆盖原始识别结果或其他足迹的确认。关联时已确认的物种也会同步，未确认时保留株记原物种。
同一足迹只能用于一个株记；已关联时显示“查看株记”，隐藏“记住这一株”和关联表单。
不确认物种也可以建档。
建档物种和首次观察说明仅在展开表单后显示；关联株记只常驻一句更改/清空物种会同步的提醒。
关联个体及删除操作仍保留确认弹窗；错误、重试与任务处理状态不隐藏。

登录页主动勾选说明后，小程序调用 `Taro.login()` 并向 Flask `/api/auth/wechat` 发送 code；H5 使用已有 zdog-auth 账号向 `/api/auth/login` 发送用户名/密码。两者均须用返回的 token 调用 `/api/auth/me` 验证身份后才显示已登录，不获取头像、手机号或位置，不回退演示身份。

Taro storage 只保存 token，启动/回到前台重新验证。验证期间显示加载；401 清除会话，网络/5xx 保留凭据供重试但不显示已登录。「我的」支持重试校验或清除本机凭据。登录切换、退出和过期会清理本机快照与页面草稿，不删除服务器记录。成功登录后按该账号重新加载私有手账。

当前没有注册、绑定、注销 UI，也未接入令牌刷新/服务端撤销。H5 与小程序身份是否关联由认证中心配置决定，不能假设昵称相同就是同一用户。用户已反馈微信登录成功。识别现已调用后台 BioCLIP，手账与照片私有保存在服务器；新增上传和业务链路尚待用户真机验证。

复用已有枝叶线稿与示例照片。四个导航图标是直接绘制的代码原生 SVG，再导出静态 PNG，不使用图像生成服务或 DOM SVG 组件。

足迹与株记互不等同：识别不会自动创建个体，关联已有植物必须明确确认。昵称/物种修改不改变个体 ID；观察可追加、编辑、删除；足迹和档案可独立删除。主流程不再注入演示记录。四个 Tab、结果和档案页均使用正式业务名称，候选局限通过说明展示，而非将产品命名为原型。
