## 发现

旧查询和照片过滤都仅接受来源`rank=species`。重新查询14个来源名称未匹配项后，发现12个目标能明确对应来源的具名`hybrid`记录，包含草莓、牡丹、矮牵牛等。原先“未匹配”不能解释为没有该植物或没有照片。

- **12项**通过严格来源名称核对，保留数据库原稳定ID及学名，另外存储来源接受名、等级、分类ID和响应指纹。
- 金叶女贞来源返回`infrahybrid`，没有擅自放宽为可接受的来源等级。
- 海滨木槿的`Talipariti hamabo`查询未得到结果，仍需明确异名证据。
- 标准化只处理独立的`×`/`x`杂交符号，不删除亚种/变种名称，不把亲本组合或相似拼写当作同一物种。
- 矮牵牛从`Petunia hybrida`关联`Petunia × atkinsiana`，依据的是来源明确列出的科学异名，不是字符串相似。

- `server/src/yizhu_server/named_hybrid_sources.py`：独立、显式的具名杂交来源核验与采集入口。

- 仍要求研究级观察、逐张CC0/CC BY许可、作者分组、单观察一图、近重复检查及4GiB空间底线。
