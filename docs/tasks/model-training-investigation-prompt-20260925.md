## 需要你回答的问题

1. **数据是否支撑目标？**分析每类数量、作者/观察独立性、器官/季节/背景/地区多样性、长尾与栽培植物缺失、标签与异名风险。分析旧图还能用于哪些目的，区分可训练、候选和范围外库存。
2. **如何定义“中国常见植物”？**提出可维护的地区、场景与分类范围；249种适合作为怎样的阶段范围，还缺什么证据？不自行改目标名单。
3. **公平比较哪些方法？**至少比较随机初始化、通用视觉预训练＋新头、植物预训练＋新头。可考虑冻结特征训练新头、部分解冻和全量微调的顺序；必要时再讨论更现代的视觉/自监督骨干。采用模型必须核实官方许可、输入规范与资源成本。
4. **二分类与未知植物拒识怎么做？**植物存在不是判断该物种在不在标签表。评估硬门控与其他策略的误拒代价，定义真实植物、假花、屏幕/照片、植物制品和多植物画面的标注规则。
5. **如何增加数据有效信息量？**不随意承诺“每种N张就能90%”；设计固定验证集、嵌套训练子集的学习曲线，确定瓶颈是数量、多样性、标签还是优化。维持授权、作者分组及跨来源去重。
6. **怎样防止再次返回未训练类别？**说明新分类头、标签ID映射、支持集合元数据和推理路径的限制，并指出这不能自动保证识别正确或拒识未知物种。
7. **怎么验收？**端到端Top-5必须以预先定义的全部目标植物样本为分母，门控误拒、技术失败、未支持目标和最终候选截断导致的漏识别均计为未命中；非植物误放行、目标外拒识单报。缺少目标种测试样本时报告覆盖缺口，不能声称全范围达标。
8. **哪一步最值得现在做？**给出一项主推荐、一项备选，以及最小有区分力的对照实验。明确哪些可沿用当前授权，哪些需要用户重新确认。
