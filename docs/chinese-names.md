# 中文植物名与分类名称

更新：2026-09-21。

## 当前来源与覆盖

- 中文首选名优先使用《中国生物物种名录 2026》，缺失时从已核验 ScienceDB 原文件补充。
- 108,372 个植物参考条目中，**19,716 个**有中文显示名称（全国名录 11,278 +
  ScienceDB 8,438）；**4,044 个目／科／属节点**有中文名称。
- 名称版本：`CoL-China-2026-v2`。名录仅展示有中文名的可见条目；完整识别参考仍保留。
- 可见条目支持中文名和学名搜索。缺少中文名的条目仅在数据库保留，公开列表、搜索和详情不提供。
- TaiCOL 补充名称、别名、异名桥接及转换依赖已移除，不再参与构建和线上显示。

## 匹配与数据边界

1. 按 **分类等级 + 学名**精确匹配全国名录，歧义项跳过，不模糊匹配、不机器造名。
2. 不使用原有手工名称配置。现已按来源规则给 196 个物种补入 241 个别名，
   并按明确要求为 8,438 个隐藏物种补入 ScienceDB 首选名并恢复可见性。
3. 全国工作簿没有异名表，不推断其他学名的同物异名关系，也不从旧参考库继承别名。
4. `chineseNameOrigin` 为 `colchina`、`sciencedb` 或 null。保留来源、版本及行定位；
   新增源不覆盖原有全国名称，分类差异只记录、不自动替换分类树。
5. 不改变 Species ID、原始 taxonomy、分类节点/成员关系或识别向量映射。
6. 识别结果、足迹和株记的物种显示名优先使用已采纳且有来源的中文别名，
   无别名时回退到名录中文名／学名；公开名录仍保留规范名称。
   仅改变返回数据的显示字段，不改写私人昵称、故事、描述或原始识别结果。

工作簿快照、校验值和许可限制见 `national-names-and-descriptions.md`。
它未附统一开放许可声明，不能标为 CC BY；不对外分发完整工作簿。
名称匹配在本地执行，不向名称来源站点上传用户照片。

## “桂花”检索别名的来源

已核对原始 XLSX 第 **30134** 行：`Osmanthus fragrans` 的“物种中文名”为“木犀”。
整个工作簿的“物种中文名”列没有恰好等于“桂花”的记录；其他名称中包含“桂花”不等于这个物种。
文件的 15 个字段没有别名列。不能将“文件不提供这个别名”说成“没有收录这种植物”，
也不能从这个导出推断全国名录网站或其他资料是否包含别名。

原 `bioclip-labels.json` 的 24 条手工中文配置已删除，旧名称不再进入显示、搜索或缺失兜底。
该文件仅保留历史学名和 ID，用于兼容旧引用及离线小集合比较，不参与线上中文名称补充。
缺失参考库时，历史 ID 只能解析为不可见的学名占位，不恢复手工中文名。
模型原始结果、用户昵称、故事和私人描述不批量清洗；明确标记的演示/测试夹具不是生产名称来源。

现已从有《中国植物志》引用的 Wikidata 俗名声明接入“桂花”，逐条保留出处，
不是恢复手工映射。完整规则、ScienceDB 补名及备份说明见 `name-enrichment.md`。

## 数据库可见性

`species.is_visible` 为持久化的 0/1 标记，Species JSON 同时输出 `isVisible`。
导入时，有有效中文名设为 1；缺失、空白或仅拉丁文字的名称设为 0。
当前 **19,716 条可见 / 88,656 条隐藏**。不是物理删除，也不修改私人 Plant 的可见性。

- 列表、搜索、分类节点计数和详情统一执行可见性限制。隐藏物种的公开详情返回 404。
- `chineseOnly=0` 为旧客户端保留，但不再允许查看隐藏条目；页面移除“全部参考”切换。
- 标签、向量和隐藏物种仍参与完整模型排序。新识别的展示候选会剔除隐藏项；
  原始首选隐藏时结果保持不确定，不将后续可见候选冒充识别成功。完整原始结果仍保存。
- 私人历史引用继续可读，已有确认和个体 ID 不变。旧候选仅在界面过滤，不改写原始记录。
  不允许新选隐藏物种，但编辑已有档案时可保留原隐藏物种引用。
- 后续补齐中文名并重建可恢复可见性，ID 不变；不靠前端开关决定数据库状态。

升级旧参考库需用下方命令写入新文件，核对后替换并重启服务清理缓存。
不要仅部署代码而继续使用缺少 `is_visible` 列的旧参考库。

## 重建

准备 `plant-catalog.md` 的 TreeOfLife 文件和全国 XLSX 后：

```sh
uv sync --project server --extra recognition --locked
uv run --project server --extra recognition --locked yizhu-catalog \
  --output server/.cache/catalog/treeoflife-10m/catalog-next.sqlite3
```

使用 `--national-source` 指定全国 XLSX 的其他路径。无需 OpenCC 或额外名称依赖组。
导入器验证固定快照，拒绝覆盖已有输出。验证名称出处、稳定 ID、分类及向量映射后，
原子切换公开参考库并重启 API。不要修改私人 `server/.data/journal.sqlite3`。
旧原始缓存和回滚备份不再参与导入，也不通过 API 提供；保留历史来源记录，不伪造旧版本出处。

## API

- `GET /api/catalog` 返回 `chineseNameCount`、`chineseTaxonCount`、`chineseNamesVersion`，以及 `visiblePlantCount`、`hiddenPlantCount`、`visibilityPolicy`。
- 分类和物种列表兼容 `chineseOnly=0/1`，均仅返回可见条目；非法筛选返回 400。
- Species 包含 `chineseName`、`chineseAliases`、`chineseNameOrigin`、`nameSources`、`taxonomyChinese`。
  `commonName` 为中文优先显示值；分类保留拉丁 `name`，另提供 `chineseName` 和 `nameSource`。
- 搜索始终绑定参数，并保持转义、分页上限。需使用包含可见性列的新参考库。
