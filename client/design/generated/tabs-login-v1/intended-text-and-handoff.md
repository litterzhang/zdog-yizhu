## 应用内预期文案（实现时以此为准，不从图中 OCR 复制）

### 三项底部导航

顺序固定：**发现 / 我的植物 / 我的**。
三张总览屏分别选中对应项，未登录“我的”屏选中“我的”。
独立登录页不显示底部 Tab。
图标由实现方采用既有代码原生图标系统，不能把图片中的导航直接贴入应用。

### 发现

- 原生标题：一株
- 小标题：自然观察手账
- 主标题：今天，遇见哪一株？
- 说明：认识它，也记住与它有关的小事。
- 主要操作：拍照识别
- 次要操作：从相册选择
- 区块：最近的观察
- 虚构观察示例：回家路上的银杏 / 银杏 · 2026.09.18
- 如空间允许的第二示例：阳台的茉莉 / 茉莉花 · 2026.09.16

### 我的植物

- 标题：我的植物
- 说明：每一株，都有自己的故事。
- 搜索占位：搜索昵称或物种
- 个体昵称（主）：回家路上的银杏
- 物种（次）：银杏
- 日期：最近观察 · 2026.09.18
- 个体昵称（主）：阳台的茉莉
- 物种（次）：茉莉花
- 日期：最近观察 · 2026.09.16

所有昵称、物种关联与日期都是虚构的设计例子，不是从账户或私人照片读取。
昵称不代表物种，物种不代表同一个体，观察记录不代表识别已经核验。

### 我的（已登录概念）

- 标题：我的
- 账户示例名称：植物观察者
- 说明：把日常的小发现，慢慢记下来。
- 菜单：识别历史 / 隐私与数据 / 关于一株
- 次要操作：退出登录
- 头像仅为中性占位，不表示已经获取微信头像或昵称。

### 我的（未登录）

- 标题：我的
- 邀请：登录，留下这一株的故事
- 说明：登录后可保存个人植物与观察记录。
- 说明：暂不登录，也可以先逛逛。
- 主要操作：去登录
- 游客操作：先去发现
- 菜单：隐私与数据 / 关于一株
- 不展示已保存的个人历史或暗示游客记录已保存到云端。

### 独立登录页（小程序概念）

- 原生标题：登录；提供返回入口。
- 工作名：一株
- 主标题：记住每一次相遇
- 说明：登录后，保存你的植物与观察记录。
- 说明：个人云端记录需登录。
- **初始同意控件为空方框，不选中。**
- 同意文案：我已阅读并同意
- 分开的可访问链接：用户协议 / 隐私政策（中间可用“和”连接）
- 提示：请先阅读并勾选协议
- 主按钮：微信登录；图中未同意状态表现为禁用浅色。
- 游客操作：暂不登录，先去发现
- 不使用手机号、密码、短信或二维码，不宣称自动获取微信头像。
